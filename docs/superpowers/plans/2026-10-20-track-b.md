# Track B Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline task-by-task. The user approved this approach; proceed without another approval round.

**Goal:** Add configurable divergence gating and a validated ranked failure handoff while preserving paper reproduction behavior.
**Architecture:** A pure boundary module summarizes fingerprinted check records. Ranked prediction validation and a versioned handoff contract integrate into the existing pipeline; separate reports expose top-k outcomes and uncalibrated confidence.
**Tech Stack:** Python >=3.10 standard library, current providers/native Ollama.
**Spec:** docs/superpowers/specs/2026-10-20-track-b-design.md

## Global Constraints

- No gold labels in generation, boundary or ranking; evaluation only.
- Existing single-output protocols remain available and semantically unchanged.
- Strict threshold >; explicit configured threshold, example0.30.
- No conclusive evidence => inconclusive, never claimed success.
- Model confidence is uncalibrated and distinct from probabilities/vote shares.
- Retain current nine-mode taxonomy; do not invent a 19-mode mapping.
- Version the new handoff separately from legacy orchestrator vote payload.

## Review Focus

- Duplicate/conflicting rule results and semantic UNCLEAR do not dilute failures.
- Invalid/NaN/bool confidence and absent evidence cannot become ranked candidates.
- Threshold alarms remain visible if ranking abstains/errors.
- Below-threshold/no-check runs and errors remain in report denominators.
- Saved payload validation rejects forged/inconsistent ranking/count decisions.
