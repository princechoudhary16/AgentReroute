# A guided AgentReroute story

The user wants a clean, animated, scroll-led website inspired by the pacing of OpenAI's GPT-6 introduction and Apple's iPhone 18 Pro page. The sequence is explicit: key ideas/findings, an explanation of the mechanism, the live agent system, then engine comparison as usable inline widgets. This continues the authorized UI redesign; implement in the current local branch and leave the server running.

Use the existing dependency-free Python/HTML app. My design choice: a quiet ivory editorial surface, oversized black typography, a mint/violet animated route illustration, then dark, full-width interactive workspaces. A sticky chapter navigation and a scroll-synchronized diagram explain one idea at a time. Motion conveys the wrong handoff, attribution and corrected route; it must not imply a live model result. Label the illustration. No invented benchmark gains or general accuracy claims.

The home route becomes the story. Preserve dedicated /system and /compare pages and all saved-run links. Embed each existing tool through same-origin /widgets/system and /widgets/compare routes. Hide duplicate page headers inside widgets, automatically size to content, and keep all current controls, traces, errors and evidence. Load widgets as their chapter approaches. Scrolling never starts a Gemini comparison. A plain-English guide above each widget changes with the currently selected event, including historical playback, errors and canceled runs. The two diagnostic engines remain sequential and use identical model settings.

Keyboard navigation, mobile layout, reduced-motion support and an explicit animation toggle are required. Do not trap scrolling or override browser gestures. Content remains visible without reveal support; no-JavaScript links open the dedicated tools. Trust widget messages only from the expected same-origin frame, preserve query run IDs when navigating inside the comparison widget, and avoid leaking future conclusions into historical explanations. Keep credentials and algorithm behavior unchanged.
